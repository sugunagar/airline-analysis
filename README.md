# Airline Analysis 🛬

Exploratory data analysis of airline data using Python in a Jupyter Notebook — cleaning the data, exploring it, and pulling out patterns.

## 📌 Live Demo

👉 https://sugunagar.github.io/airline-analysis/

## About the Project

This project works through an airline dataset end to end: loading and cleaning the data, exploring distributions and relationships, and summarizing what the data shows.

## Files

- `Airline_data.csv` — the dataset used for the analysis
- `airline_analysis.ipynb` — the analysis notebook 
- `requirements.txt` — Python dependencies

## Tech Stack

- Python
- Pandas
- Jupyter Notebook

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/sugunagar/airline-analysis.git
   ```
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Open the notebook in Jupyter and run the cells in order.
